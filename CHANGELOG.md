# Changelog

All notable changes to `sorodoc-dashboard` will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] - 2026-11-02

### Added
- Interactive Next.js 16 Web Dashboard for visualizing Soroban contract specifications.
- Local WASM file drag-and-drop / upload inspector.
- Live Soroban RPC contract lookup by on-chain contract address.
- Multi-tab viewer: Markdown Documentation, TypeScript Client, OpenAPI 3.0 Schema, and Normalized AST (JSON).
- One-click copy-to-clipboard and file download export capabilities.
- Robust error handling for invalid WASMs and unreachable RPC nodes.
- Full automated test suite with React Testing Library covering UI interactions and real Soroban WASM artifacts.
